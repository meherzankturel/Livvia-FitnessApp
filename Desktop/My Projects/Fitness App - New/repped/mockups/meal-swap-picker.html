What's new in the swap picker

The picker turns a flat list into a categorized browse, while reinforcing the dietary preference at the top.

Categorization

  • Cuisine filter chips at top — "All" plus each selected cuisine
  • Below: alternatives grouped by cuisine with thin section dividers
  • Each group shows option count + a small category color bar

Dietary safety

  • "VEGETARIAN ONLY" pill in the hint line reminds the user their preference is locked
  • The algorithm already filters non-veg out — this is just the visual reinforcement
  • If the user later changes diet in Settings, this pill updates

Macro hint chips (optional)

  • "+8 P" or "−40 kcal" badges show how the alternative compares to the current meal
  • Goal-aware: muscle-gain users see protein deltas; fat-loss users see calorie deltas

No more icons

  • Cuisine emojis removed — clean text-only labels
  • "Indian" instead of "🇮🇳 Indian", etc.
  • Visual differentiation comes from category color bars only
