How It Works
👉
Click any card to toggle between collapsed and expanded. Card #1 is expanded by default so you can see both states. Try clicking the others.
Collapsed State
📷
56×56 thumbnail with muscle-group color tint + exercise image/emoji. Compact row: name, meta, weight, chevron. Just enough to scan the full workout at a glance.
Expanded State
🎨
Full-width image area (180px tall) — the thumbnail explodes into a large hero zone with subtle contour decoration and the muscle-group color tint. In the real app, this shows the actual AI-generated exercise image.
🏷
Muscle + type tags — colored pills (Chest, Compound, etc).
🔢
Stats grid — Sets / Reps / Weight in 3 equal stone-colored cells. Large numbers, tiny labels.
⛰
Focus cue — terrain-styled green card with mind-muscle connection instructions. The coaching voice.
📈
Last session reference — "75kg × 8 reps · Today: +2.5kg". Personal, motivating, contextual. Pulls from your actual set_logs data.
In React Native
✅
Animated.Value for height — collapsed ~76px, expanded ~auto (measured with onLayout). Spring transition. The trail line stretches naturally because it's absolutely positioned from top to bottom of the parent.
📸
Exercise images — you already have 55 PNG images in assets/exercises/. The collapsed thumbnail uses the same image as the expanded hero, just cropped smaller. No extra assets needed.
