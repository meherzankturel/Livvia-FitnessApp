What premium direction fits Repped?

Each direction pulls different components from the libraries. Pick the one that matches your vision — or mix elements.

A

Refined & Minimal (Apple / Linear style)

Vibe: Calm confidence. Every motion is earned and purposeful.

Key effects:

  • Smooth spring transitions between screens (fade + subtle slide)
  • Counting number animations for stats (0 → 87%)
  • Progress ring animated fill on mount
  • Staggered card entrances (200ms delay cascade)
  • Floating label inputs in onboarding
  • Skeleton shimmer loading states

From libraries: Animate UI counting numbers, sliding numbers, shimmer text • Aceternity focus cards, floating navbar, tabs • Jitter micro-interactions (toast, dialog easing curves)

Think: Apple Fitness+, Linear app, Stripe dashboard

B

Bold & Expressive (Aceternity / Hover.dev style)

Vibe: Wow factor. Interactions feel alive and surprising.

Key effects:

  • 3D tilt cards for exercises (gyroscope-driven on mobile)
  • Spotlight/glow effects on achievement badges
  • Parallax scroll on home screen header
  • Magnetic press effects on buttons
  • Background gradient animations on key screens
  • Expandable cards with spring physics
  • PR celebration with particle burst

From libraries: Aceternity 3D cards, spotlight, aurora background, expandable cards, sparkles • Hover.dev 3D sections, countdown • Animate UI particles, tilt, magnetic effect

Think: Nike Training Club, Strava premium, Superhuman

C

Playful & Energetic (Fitness-native style)

Vibe: Motivational and gamified. The app cheers you on.

Key effects:

  • Bouncy spring animations on everything (overshoot easing)
  • Confetti/fireworks on workout completion & PRs
  • Pulsing glow on active workout timer
  • Animated streak flames for consistency
  • Badge unlock animations with scale-bounce + shine sweep
  • Rolling/flipping numbers for live stats
  • Ripple button effects on CTA presses
  • Heatmap cells that pop in with staggered scale

From libraries: Animate UI fireworks, ripple button, rolling text, flip button • Aceternity sparkles, meteors, moving border • Hover.dev countdown, loaders • ReactBits animated counters

Think: Duolingo, Ring Fit, Peloton celebrations

Note: All options respect your Expo Go constraints (no reanimated, no SVG, no linear-gradient). Everything uses React Native's built-in Animated API.
