The Heartbeat System
💓
Unified 2.4s rhythm — every pulsing element shares one heartbeat CSS variable. The "Ready" dot, stat orb glows, cell wave, readiness ring glow, and CTA aura all breathe in sync. The UI has a resting heart rate.
🎮
During workout: the heartbeat accelerates (1.6s). After completion: it decelerates (3.2s) to a calm resting state. The app literally calms down with you.
Bioluminescent Glows
🔬
Stat orbs emit light from within — not a border glow or shadow. A radial gradient inside each card pulses with the heartbeat. Indigo for progress, green for health, amber for PRs. Like deep-sea creatures.
🌈
Membrane blobs — three huge blurred color shapes drift slowly behind the UI. They're almost invisible (4% opacity) but create a living, shifting warmth underneath the white surface. Like cells under a microscope.
Cellular Progress
🧬
Progress = cell division. Each day is a "cell" that divides into existence with a mitosis animation (starts as circle, splits into rectangle). Completed cells have a pulse wave that travels left-to-right like an electrical signal through a nerve.

After: living cellular strip
Muscle Fiber Icons
🧠
Exercise icons have fiber lines that contract and relax on the heartbeat. Three horizontal lines inside each icon scale between 70% and 100% width. Subtle but alive — like you're looking at actual muscle tissue.
🔄
Living card borders — a conic-gradient slowly rotates around each exercise card's edge. 80% transparent, 20% faint indigo. Like a cell membrane with an active transport region.
What Makes This Unique
✨
No other fitness app does this. Strava, Nike, Hevy, Strong — all have static UIs with occasional animations. This is a UI that's always subtly moving, always alive. It's calm, not chaotic. Organic, not mechanical.
⚠️
Expo Go compatible: Every effect here uses only Animated API spring/timing, opacity, transform, and backgroundColor. No SVG (readiness ring uses border trick in RN). No reanimated. No gradients (membrane blobs become animated opacity Views).
